# ام‌دی‌اف‌کار | MDF Kar
پروژه اندروید برای کابینت‌سازها، ام‌دی‌اف‌کارها و نجارها.

## وضعیت
نسخه آغازین: رابط فارسی/انگلیسی، ورود ابعاد پروژه و محاسبه اولیه نمونه.

## مسیر توسعه
آنالیز قطعات، نقشه بهینه برش، PVC، محاسبه ورق، ابعاد دقیق کابینت و کشو، PDF چاپی، یراق‌آلات، قیمت‌گذاری، سفارش‌ها و حساب مشتری.

**توجه:** خروجی این نسخه صرفاً نمونه اولیه است و نباید به‌عنوان نقشه برش اجرایی استفاده شود.
